# EqHub · 多源地震预警研判台

**发布页**：https://thudou.github.io/EarthQuake

EqHub 是一个跑在 Windows 上的多源地震预警研判台：减灾所与国家预警网优先，台网速报与全球台网补位；声光报警、远场倒计时、同震比对、可选 NTP 校时，都在一个窗口里。

## 获取安装包

安装包不随本页公开，需授权 GitHub 账号：

1. 接受私有仓库 [`THUDou/EarthQuake-dist`](https://github.com/THUDou/EarthQuake-dist) 的邀请；
2. 登录获授权的 GitHub 账号；
3. 打开 [Releases](https://github.com/THUDou/EarthQuake-dist/releases) 下载 `EqHub_v1.1_20261118.zip`。

未获授权访问 Releases 可能显示 404。GitHub 负责鉴权，本页不设账号体系。

## 边界

- 只读接收公开数据，不发布、不转发、不上传任何预警信息；
- 不替代官方预警系统，官方预警以中国地震局、成都高新减灾研究所发布为准；
- 本仓库只含发布页静态文件；安装包在私有仓库按授权分发。
